Getting Started

Choose a category, enter its station range or point type, then add it to the diagram. Use the Labels list to control Type/Value, Station, and Sum for each included category. Add categories from the list and remove them with ×.

Use File → Save Project to save an editable JSON file, or File → Load Project to continue later. File → Share Project Link creates a project-specific link. Export → Print opens the print dialog; Export PDF opens the same dialog with a PDF filename suggestion; Export JPG saves page images.
